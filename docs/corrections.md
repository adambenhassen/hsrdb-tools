# Corrections from publications

A few COD CIFs cannot give a correct pattern as deposited, but the original article states what the file leaves out or gets wrong. For these, hsrdb-tools applies a correction after reading the CIF. The CIF files are not changed. The corrections are in [`hsrdb_tools/corrections.json`](../hsrdb_tools/corrections.json), each with its source; the corrected entry says so in its comment in HighScore ("Corrected from the publication: …"), and the build report notes it.

A correction is added only when the article itself gives the missing information, checked by reading it.
